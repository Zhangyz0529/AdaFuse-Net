# Adaptive attack API

Use PrototypeClassifier(model,prototypes,model.right_tower.embedding,is_b7=True) with an evaluated AdaFuse model and detached clean support prototypes. attack(...,mode="joint",steps=20,restarts=5,epsilon_stat=0.1,epsilon_seq=10,alpha_stat=0.01,alpha_seq=1,seed=42) returns legal-budget candidates and gradient diagnostics. For a gate-aware variant, set gate_target="w_seq" or "w_stat",beta=0.5. Attack malicious queries only; benign queries and support are unchanged. The classifier uses negative unsquared Euclidean logits,softmax temperature1 and fixed threshold0.5 by default.

Forward uses rounded/clipped integer embedding lookup; backward uses adjacent-embedding interpolation BPDA. This is not the exact derivative of integer bytes. Restart0 starts clean; remaining restarts use uniform box initializations. Initialization and every iteration/final candidate are considered. Candidate ranking is evasion-success first,then objective. For no success, the maximum-objective candidate including clean is retained. All positions are eligible. Physical packet validity and convergence are not certified. Do not use this classifier unchanged for a squared-distance evaluation and call it the same attack.
